# 元素化学 · 色谱

基于宋天佑《无机化学》第4版下册的物质颜色与状态训练网页。题目不预先保存，而是按照 ChemQuizFormat 从规范化物质数据库现场生成。

## 使用

双击 `启动本地题库.bat`。浏览器会打开：

```text
http://127.0.0.1:3000
```

启动器使用开发模式按需编译，不会覆盖 VPS 使用的生产构建。窗口中还会列出局域网访问地址；同一局域网内的设备可以通过该地址访问。关闭启动窗口即可停止服务。

## 当前题目格式

- 物质 → 颜色：四选一。
- 颜色 → 单一物质：四选一。
- 颜色 → 物质：六项多选，含二至三个正确项。

颜色判定使用一套显式维护的术语关系：教材原始写法与标准术语双向对应，标准术语之间再按“可接受作答”建立单向连接。例如教材写“浅黄色”时可以回答“黄色”；颜色范围及其中间色则按人工校对后的关系判断。只描述明暗、不包含具体色相的“深色”不作为有效颜色答案。

“物质 → 颜色”单选题会对四个选项做严格的两两防混淆检查：任意两个选项的可接受颜色集合都不能相交。因此，“棕红色”和“淡红色”虽然不能直接互换，但都可接受“红色”，不会同时出现在同一题中。“颜色 → 单一物质”题只要求正确物质接受题干颜色、错误物质不接受题干颜色；不同物质选项彼此之间不作额外限制。干扰项仍会以较高概率优先选择中心或主元素相同的其他化合物。

所有题型共用“考察元素”范围。可以多选教材章节分组、全选，或在元素周期表上逐个选择；氢和稀有气体也可以正常选择。另有第四周期过渡金属、类金属、活泼非金属、常见变价金属、典型配位与有色离子、常见两性元素等竞赛重点预设。预设会替换当前范围，章节分组则以并集方式组合。考试模式使用开始考试时的元素范围，未来新增并接入统一生成器的题型也会自动遵守这一限制。

附录中的范围或备选颜色会拆分为同一物质的多个教材颜色，并结合人工维护的范围端点和中间色关系判定。例如 `(NH4)2S｜黄-橙` 对应黄色到橙色的范围，范围内已登记的颜色均可判为正确。

答案提交后显示教材原句，并在题目下方列出对应教材页。颜色 Quiz 和方程式 Quiz 共用项目根目录下唯一一份 `pages/original` 教材页图片，通过 `/page-images/` 按需加载。页面以教材印刷页码为主，PDF 页码仅作为辅助定位。

练习模式只会把已经点击“确认答案”的题目加入记录，可以用“上一题”“下一题”反复查看这些题目和解析。切换题型或跳过未作答题目只会替换当前新题，不会增加练习编号。颜色选物质题会展示每个选项的实际颜色、原句、页码和教材扫描页。

考试模式可设置限时、三种题型各自题量和试卷总分；题目随机混排、等权计分。考试中可以使用上一题、下一题或题号导航返回并修改答案，交卷或超时后统一评分，并提供全部题目、作答结果、正确答案和教材出处。

题目历史、答案、练习统计、元素范围、考试进度和最近一次考试结果会自动保存在当前浏览器的本地存储中。刷新或再次打开网页时，页面会询问是恢复这些记录，还是清空后重新开始；如果已作答练习与考试记录总数为 0，则直接开始，不显示恢复询问。记录不会上传，也不会在不同设备或不同浏览器之间同步；数据库版本变化时不兼容的旧记录会自动清除。

## 数据

- 主数据库：`data/chemistry.sqlite`
- 浏览器运行数据：`public/materials.v1.json`
- 题目格式：`public/question-formats.cqf.json`
- 数据构建：`tools/build_database.py`
- 颜色术语及关系：`tools/color_policy.py`
- 数据与 mhchem 校验：`tools/validate_dataset.mjs`

修改颜色术语关系后，运行数据构建脚本重新生成数据库与浏览器数据，再执行测试和网页构建。构建过程会检查颜色映射、连接和范围引用的格式，并拒绝“深色”等不合规术语。

## 管理员数据控制台

控制台使用独立地址 `/chemquiz-control`，前台导航不显示入口；地址隐藏不作为权限机制，所有 `/api/admin/*` 请求都会在服务端校验当前账户的管理员角色。控制台支持注册开关、代建注册账户、账户检索、用户名与启用状态管理、密码重置、会话撤销，以及游客/注册账户的原始数据和做题记录管理。敏感变更会写入 `admin_audit_logs`。

首次部署时设置 `CHEMQUIZ_ADMIN_USERNAME` 和至少 12 位的 `CHEMQUIZ_ADMIN_PASSWORD`。系统会在账户表中不存在该用户名时创建管理员；若同名普通账户已经存在，系统会拒绝自动提权并在服务端日志中报告冲突。管理员创建成功后可以移除这两个引导环境变量，密码不会在重启时被覆盖。

## Windows Demo 生成

需要发布新版本时双击 `生成Windows Demo.bat`。程序会自动构建网页、校验数据、汇集全部教材页图片、编译本地启动程序，并生成可直接复制到其他 Windows 设备的文件夹：

```text
release\ElementChemistryDemo
```

请完整复制该文件夹，保持 `ElementChemistryDemo.exe` 与 `resources` 目录的相对位置不变。生成程序不再创建 ZIP；如果存在旧版 `ElementChemistryDemo-Windows-x64.zip`，下次生成时会自动删除。

日常修改和测试不需要运行打包程序。
