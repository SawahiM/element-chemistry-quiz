# 化学式记录与显示规范

## 结论

本项目把“身份、检索、显示、结构”分成不同字段，不使用任一种字符串承担全部职责。

1. `formula_canonical`：可检索、可比较的规范纯文本，例如 `[VO2(O2)2]^3-`。
2. `formula_mhchem`：浏览器显示输入，通常与规范纯文本一致，由 `\ce{...}` 解释。
3. `formula_source`：教材 OCR 原始 LaTeX，仅作为审计来源。
4. `focus_element`：用于学习型干扰项的中心或主元素，例如 `PbO2`、`PbO`、`PbCO3` 均为 `Pb`，`Na2CrO4` 为 `Cr`。
5. `smiles`、`inchi`、`inchi_key`：可选结构标识；仅在能够可靠确定结构时填写。

`focus_element` 由规范化化学式按启发式规则生成：优先选择过渡元素、镧锕元素及常见重/主族中心元素；若没有，则排除氢、氧和常见碱金属/碱土金属对离子后选择首个有效元素。它用于提高题目难度，不作为物质身份或严格结构化学结论。

## 方案选择

- **mhchem** 专门排版分子式、离子、同位素和反应式。CTAN 说明：<https://ctan.org/pkg/mhchem>
- **KaTeX + mhchem** 适合当前网页：体积较小、浏览器渲染快，且可离线打包。KaTeX 扩展说明：<https://katex.org/docs/libs.html>
- **MathJax + mhchem** 同样完整，但当前界面不需要 MathJax 更广泛的数学输入功能。说明：<https://docs.mathjax.org/en/latest/input/tex/extensions/mhchem.html>
- **SMILES** 是结构线性表示，并非分子式排版语言；OpenSMILES 规范：<https://opensmiles.org/opensmiles.html>
- **InChI/InChIKey** 用于结构身份与数据库互联，不适合直接展示给学习者。IUPAC 说明：<https://iupac.org/who-we-are/divisions/division-details/inchi/>
- **CML** 能保存分子、键、性质等丰富语义，但对本题库的简单颜色问答过重。规范：<https://www.xml-cml.org/spec/>
- 若以后加入结构式编辑，可考虑开源的 Ketcher；当前阶段不引入。项目：<https://github.com/epam/ketcher>

## 为什么不只存 LaTeX

OCR LaTeX 中包含 `\mathrm`、`\left`、布局空格等排版噪声。同一物质可能有多种等价写法，直接以 LaTeX 作为主键会制造重复数据。因此数据库用规范纯文本建立身份键，原始 LaTeX只进入别名和来源表。

## 可覆盖的无机化学写法

```text
H2O                 普通分子式
[VO2(O2)2]^3-       配离子与电荷
CuSO4·5H2O          结晶水
^235U               同位素
Fe^3+               单原子离子
3PbO·H2O            化学计量组合
```

网页显示时包装为 `\ce{...}`，例如 `\ce{[VO2(O2)2]^3-}`。

## 无法安全推断时

附录中的分子式不等于确定的二维结构。没有可靠结构来源时，不自动生成 SMILES 或 InChI，也不根据经验猜测配位键连接方式。
